# 硬件与引脚

> 来源：《PIN_MAPPING.md》《EdgeOS Gateway 产品参数》《edgeos-board-hardware-plan.md》《edgeos-dual-storage-partition-plan.md》

## 硬件平台规格

| 组件 | 规格 |
|------|------|
| 主控 | ESP32-P4（双核 RISC-V 360MHz，32MB PSRAM / 32MB Flash） |
| 显示 | 4 英寸 720x720 MIPI DSI IPS（ST7703），GT911 五点触控，400cd/m² |
| Zigbee | ESP32-C6 RCP，SDIO 连接，信道 15，最大 32 子设备 |
| 网络 | RJ45 百兆以太网（IP101 PHY）+ USB-C NCM 虚拟网卡 |
| 板载外设 | 1 路 RS485（SP3485EN，自动方向）、2 路继电器、GPIO、ES8311 音频（含 MIC）、TF 卡座 |
| 硬件平台 | ESP32-P4-Function-EVB-Board v1.5.0 / Waveshare ESP32-P4-WIFI6-Touch-LCD-4B（板名含 WIFI6，但本产品**不使用 WiFi**） |

## 关键引脚分配（GPIO）

| 功能 | 引脚 | 备注 |
|------|------|------|
| P4↔C6 SDIO | 18/19/14/15/16/17（CLK/CMD/D0-D3），EN=54，BOOT=6 | C6 电源时序与错误恢复由 rcp_sdio.c 管理 |
| DSI 屏幕 | RST=27，背光 BK_EN=33 | |
| GT911 触摸 | I2C SDA=7，SCL=8，INT=3 | |
| ES8311 音频 | I2S 9-13，功放 PA=53 | |
| 以太网 IP101 | MDC=31，MDIO=52，RST=51 | ⚠️ **GPIO35 为 RMII 专用，绝对不可挪用**，挪用会导致网络异常 |
| RS485 | UART1 TX=47，RX=48，自动方向控制 | 串口参数运行时热切（默认 9600 8N1，视设备而定） |
| 继电器 1/2 | GPIO32 / GPIO46 | |
| USB | D+/D- = 24/25 | NCM 需烧 eFuse USB_PHY_SEL=1（**不可逆**） |
| 调试串口 | P4：GPIO37/38（UART0 115200）；C6：GPIO16/17 | |
| TF 卡 | SDMMC 4-bit GPIO39-44，电源控制 GPIO45 | 与 C6 SDIO 不冲突；用于大容量日志/备份/OTA 包外置 |

## Flash 分区表（partitions.csv，32MB）

| 分区 | 偏移/大小 | 用途 |
|------|-----------|------|
| nvs | 24K | 运行时配置（config_mgr） |
| otadata | 8K | OTA 启动槽记录 |
| ota_0 / ota_1 | 各 6M | 固件双槽（自动切换 + 崩溃回滚） |
| zb_storage | 16K | Zigbee 持久化 |
| storage_0 / storage_1 | 各 3M | Web UI 双槽（storage_mgr 管理，NVS key `storage/active_slot`） |
| database | 2M @0x1025000 | 预置 SQLite（edgeos.db） |
| fonts | 4M @0x1500000 | 中文字库（cn_24/cn_32/lucide_icons） |

> storage 拆双槽是为了解决"更新 Web 丢数据库"问题；OTA 更新 storage 时自动写非活跃槽并切换（v1.0.0 起免手动）。

## 已验证硬件状态

已验证：DSI 屏、触摸、继电器、RS485、音频、MIC、以太网、C6 SDIO 传输。
待确认：USB NCM 需硬件确认 R51/R106/R107 跳线。
注意：硬件实际**仅 1 路 RS485**；第二路需 P3 排针 GPIO2/3 外接模块或改版。
