# 网络与端口

> 来源：《EdgeOS 网关使用手册》《appendix-b-mqtt-topic-spec.md》

## 端口总表

| 接口 | 协议 | 端口 | 用途 |
|------|------|------|------|
| Web 后台 / REST API | HTTP | 80 | `http://<网关IP>/`，管理与对接接口 |
| WebSocket | WS | 80 `/ws?token=xxx` | 浏览器实时推送（Token 鉴权，环形缓冲 20 条重放） |
| TCP Server | TCP | 8888 | 事件推送（JSON + 换行，最大 8 客户端），开关/端口可在系统设置改 |
| MQTT Broker | MQTT 3.1.1 | 1883 | 本地设备/系统接入（无认证、无 TLS、无 ACL，仅限可信局域网） |
| MQTT Client | MQTT 3.1.1 | - | 网关作为客户端连接外部 Broker（云桥接） |

MQTT Broker 限制：最大 64 客户端、主题 128B、Payload 4KB、每客户端 16 个订阅、QoS 0-1（**不支持 QoS2**）。

## 默认账号

| 项 | 值 |
|----|----|
| 用户名 | `admin` |
| 初始密码 | `admin123`（**首次登录强制修改**） |

- 设备无用户时自动创建默认 admin
- 生产部署必须立即修改默认密码；RBAC 三级权限（admin/用户/访客）
- 对接程序建议用「永久对接令牌」：Web 后台 → 用户管理 → 生成 API Token（NVS 存储、api 用户、admin 权限），避免 24h 过期的登录 Token

## 如何知道网关 IP

1. **串口日志**：上电后 UART0（GPIO37/38，115200）打印 IP（最可靠）
2. **路由器后台**：查找 DHCP 客户端列表中的设备
3. **Web 后台**：系统设置 → 有线网络 可查看/切换 静态 IP 或 DHCP
4. USB NCM 虚拟网卡：网关侧静态 IP（192.168.5.1/24 或 192.168.7.1/24，两处文档记录不一致，以实际枚举为准）

## 网络排障要点

- 无法访问 Web：先查 RJ45 链路灯 → 再看串口日志打印的 IP → 确认 PC 与网关同网段
- GPIO35 是 RMII 专用引脚，任何挪用都会导致以太网异常（常见于自行改板场景）
- NTP/时区默认 CST-8，以太网连接后 SNTP 自动启动；未联网时定时规则会在错误时间轴运行
- 设备无 WiFi 功能（P4 无射频授权 + C6 仅作 Zigbee RCP）
