# 系统概况与架构

> 来源：《EdgeOS 产品架构白皮书》《EdgeOS Gateway 产品参数》《版本号维护规范》

## 产品定位

EdgeOS 是基于 ESP32-P4 的**边缘物联网智能网关**（4 英寸 720×720 触控面板，86 盒形态，壁挂/桌面）。设计理念：**Cloud is Optional, Edge is Required** —— 断网仍可完成设备联动、场景执行、规则触发。

- 屏端（LVGL）做**控制**，Web 后台做**管理**（完整配置端）
- 微服务 + 事件总线架构：EventBus 是唯一通信通道，200+ 事件/秒
- 业务运行期全走 PSRAM 内存缓存，SQLite 由 WriteBack 异步落库（业务零 SQLite 直接触碰）

## 双芯片异构架构

| 芯片 | 角色 | 说明 |
|------|------|------|
| ESP32-P4 | 主控 | 双核 RISC-V @360MHz，32MB PSRAM + 32MB Flash，跑全部业务（17+ 服务、8 驱动、LVGL 屏端、Web 后台） |
| ESP32-C6 | Zigbee RCP | 纯射频协处理器（802.15.4），跑完整 Zigbee 协议栈在 P4 上（ZCZR Coordinator，信道 15，最大 32 子设备），经 SDIO 4-bit @5MHz 连接（自定义 RPC 协议，magic 0x5A5B） |

## 五大子系统

1. **HMI**：4 英寸 LVGL 屏端（5-tile 滑动视图、动态字库、SIMD 优化）
2. **Gateway Service**：http_server（~80 REST 路由 + WS）、mqtt_broker（内置 1883）、mqtt_client（云桥接）、rule_engine、scene_engine、alarm_center、history_service、ota_service
3. **Driver Manager**：南向驱动（modbus RTU/TCP、mqtt、relay、gpio、screen、tcp、zigbee），统一抽象为 device_t
4. **Hardware**：以太网（IP101）、USB NCM、RS485、继电器、ES8311 音频、TF 卡
5. **Cloud**：MQTT 云客户端 + OTA 服务器对接（当前为可选项）

## 技术栈

| 层 | 技术 |
|----|------|
| 固件 | C，ESP-IDF v6.0.1，FreeRTOS SMP 双核 |
| 屏端 | LVGL v9 |
| Web 前端 | Vue3 + TS + Vite + Element Plus + Pinia + ECharts（深色主题） |
| Web 后端 | esp_http_server 原生，20 个 handler 模块 |
| 数据库 | SQLite3（内存 DB + WriteBack 异步持久化，VFS 跑在 LittleFS） |
| 消息 | 自研 MQTT 3.1.1 Broker（QoS0/1 + Retain + Wildcard，64 客户端） |

## 版本号规则（重要）

- 版本号由 **git tag** 决定：`git describe --tags --dirty` 自动生成 `v + x.y.z.w` 四段
- 发布四步：`git commit → git tag v1.0.0.x → build_p4.bat → 上传 OTA`
- 后缀含义：`-dirty`（有未提交修改）、`-N-gxxxx`（落后 N 个提交）
- 查看当前版本：Web 后台「关于」或 `GET /api/v1/system/info`
