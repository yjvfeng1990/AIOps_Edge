# 构建与烧录

> 来源：《EdgeOS 网关使用手册》《版本号维护规范》

## 环境要求

- ESP-IDF v6.0.1（P4 工程；C6 是独立工程 c6_rcp_build）
- Python 3.11+（工具链 db_prebuild / gen_manifest / gen_fonts）
- Node.js 18+（Web 前端）
- 串口：P4 = **COM9**，C6 = **COM11**（flash_c6.bat）/ COM21（monitor，文档两处记录不同，以设备管理器实际为准）

## 构建脚本（项目根目录）

```bat
build_p4.bat        :: P4 固件（自动先跑 tools\db_prebuild.py 生成 edgeos.db）
build_c6.bat        :: C6 RCP 固件（cd c6_rcp_build && idf.py build）
build_web.bat       :: Web 前端 → npm run build → 复制 dist 到 spiffs_data\www
Full_build.bat      :: 全量 Clean Build（含清理 stale managed_components）
```

版本号在构建时由 `git describe --tags --dirty` 注入 —— **先 commit 再打 tag 再构建**，否则版本号带 -dirty 后缀。

## 烧录脚本

```bat
flash_p4.bat        :: P4 全量（分区表+固件+字库+数据库），COM9，自动跳过 storage_1 备份槽
flash_app.bat       :: 仅 P4 应用（跳过 storage_1 + fonts）
flash_fonts.bat     :: 仅字库分区 @0x1500000（需先 gen_fonts.bat）
flash_db.bat        :: 仅数据库分区 @0x1025000
flash_c6.bat        :: C6 烧录（app 偏移 0x20000，dio 80m，2MB）
erase_flash.bat     :: 整片擦除（COM9）—— 会清空全部配置与数据，慎用
```

> flash_p4.bat 会过滤 storage_1（防止覆盖 Web UI 备份槽）；脚本内部注释有一处笔误写 "only"，实际行为是过滤。

## C6 进入下载模式（手动）

按住 **BOOT** → 按一下 **RESET** 松开 → 松开 **BOOT**。C6 固件升级目前**只能串口刷写**（无 OTA 通道）。

## 串口监控

```bat
:: P4（UART0 115200）
idf.py -p COM9 monitor

:: C6（需进入 c6_rcp_build 目录）
cd c6_rcp_build
idf.py -p COM21 monitor
```

也可用工具 `tools/monitor_serial.py` 采集串口日志。串口日志同时镜像进 Web 日志中心（logs_vprintf 钩子）。

## 烧录场景速查

| 场景 | 做法 |
|------|------|
| 全新板子 | flash_p4.bat + flash_c6.bat |
| 只改了固件代码 | flash_app.bat（或走 OTA） |
| 中文显示方块 | gen_fonts.bat → flash_fonts.bat |
| Web 页面更新 | build_web.bat 后 flash（或走 OTA storage 组件） |
| 数据库结构变更 | db_prebuild 后 flash_db.bat（⚠️ 会覆盖运行数据，先备份） |
| 系统彻底异常 | erase_flash.bat → 全量重刷 |
