# 已知限制与安全

> 来源：《LOG1.md》《edgeos-security-framework-plan.md》《edgeos-plan-index.md》

## 安全风险（公网部署前必读）

| 风险项 | 现状 | 影响 |
|--------|------|------|
| MQTT Broker 无认证/ACL/TLS | 未实施（Security P1） | 局域网内任何人可读写设备主题 |
| HTTP 无 HTTPS | 未实施 | 凭证明文传输 |
| OTA 固件无 RSA 签名验证 | 未实施 | 升级包可被替换（MitM） |
| OTA 下载无鉴权 | 下载/manifest 公开 | 升级包可被任意下载 |
| Secure Boot V2 | 未实施（且烧 eFuse **不可逆**，务必谨慎） | 固件可被替换 |
| USB NCM eFuse | 需烧 USB_PHY_SEL=1（不可逆） | 硬件一次性操作 |

**结论：当前定位可信局域网使用；公网部署前必须完成 Security P1（MQTT ACL/TLS、HTTPS、OTA 签名）。**

认证与权限已实现：salt+SHA-256 密码、Token 24h + 永久对接令牌、RBAC 三级（admin/用户/访客）、49 处审计点。

## 未完成功能（P0~V2 摘要）

- Phase G 端到端联调（50+ 子设备压测、IAS Zone 配网）未完成
- 冷启动优化：当前 20~32s（目标 <10s）
- Zigbee：scan/join/match_desc 3 个 stub、网络管理（信道/PAN 变更）、Zigbee OTA 均未实现
- C6 固件无 OTA 通道（只能串口刷）
- Recovery Mode、防降级检查未实施
- Engineering Mode（RS485 透传/Zigbee 报文监听）未实施
- TF 卡大容量日志/备份/OTA 外置：计划中
- 双路 RS485：硬件仅 1 路，第二路需 P3 排针 GPIO2/3 外接

## 性能基线

- EventBus 200+ 事件/秒
- SQLite 运行期读写全走 PSRAM 内存缓存（WriteBack 异步落库）
- MQTT Broker 64 客户端上限
- Zigbee 最大 32 子设备（信道 15）
- 冷启动 20~32s（已知待优化）

## 运维部署红线

1. 不做公网暴露；如需远程，走 VPN 或反向代理（自行加固）
2. 修改默认 admin 密码是上电后第一件事
3. OTA 服务器（10.10.0.6:8080）同样仅限内网；上传 Token 勿泄露
4. erase_flash / flash_db 会清数据，操作前确认备份
5. fonts/database OTA 无回滚，升级前保留 bin 备份
